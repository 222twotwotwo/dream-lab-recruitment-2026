## 1. 文档说明

### 1.1 目的与读者

- 目的：把需求文档中的功能用**用例图**与**业务流程图**可视化，用于评审、开发排期与测试用例设计。
- 读者：产品、前后端开发、测试、实验室管理员。

### 1.2 编号约定

| 前缀 | 含义 |
| --- | --- |
| `BP-xx` | 业务流程图（Business Process），第 3 章 |
| `UC-xx` | 用例（Use Case），第 4 章 |

### 1.3 图例

**业务流程图**

| 符号 | 含义 |
| --- | --- |
| 矩形 | 动作 / 步骤 |
| 菱形 | 判断（分支上标注 是/否） |
| 实线箭头 | 流程流转 |
| 虚线箭头 | 通知 / 触发 / 异步关系 |

**用例图**

| 符号 | 含义 |
| --- | --- |
| 矩形节点 | 参与者（Actor，带角色名） |
| 圆形节点 | 用例 |
| 实线 | 参与者与用例的关联（谁能发起该用例） |
| 虚线 | 包含关系（执行该用例时必须执行另一个用例） |

## 3. 业务流程图

### BP-00 端到端总览（角色视角）

```mermaid
flowchart TD
    A[管理用户：创建课题与模块<br/>配置联系方式与二维码<br/>发布] --> B[学生：浏览与筛选课题]
    B --> C{课题开启审核}
    C -- 是 --> D[学生：报名并提交申请书]
    D --> E[管理用户：评审申请书]
    E -- 通过 --> F[学生成为课题成员]
    E -- 待定 --> W[等待后续评审]
    E -- 拒绝 --> X[结束：按配置释放名额]
    C -- 否 --> F
    F --> G[管理用户：分配模块与任务]
    G --> H[学生：执行任务并更新进度]
    H --> I[成员：提交成果]
    I --> J[管理用户：审核成果]
    J --> K[成果公开展示]
    K --> L[课题完成：成果归档<br/>看板与报表统计]
```

### BP-01 注册与认证

```mermaid
flowchart TD
    A[打开注册页] --> B[填写邮箱、密码、学号、班级、姓名]
    B --> C[请求邮箱验证码]
    C --> D{发送频率与邮箱格式校验}
    D -- 不通过 --> E[提示错误并返回修改]
    E --> B
    D -- 通过 --> F[发送验证码邮件]
    F --> G[输入验证码并提交注册]
    G --> H{验证码有效且未使用}
    H -- 否 --> I[提示验证码错误或过期]
    I --> G
    H -- 是 --> J{邮箱与学号唯一且密码合规}
    J -- 否 --> K[提示具体错误]
    K --> B
    J -- 是 --> L[创建用户：角色 USER，邮箱标记已验证]
    L --> M[跳转登录页完成登录]
    M --> N[结束]
```

**关键规则**：BR-01（邮箱/学号唯一）、NFR-SEC-01/03（bcrypt、验证码限流）、REQ-AUTH-06（注册后需审核方可报名，可配置）。

### BP-02 课题生命周期（管理用户 + 系统自动流转）

```mermaid
flowchart TD
    A[管理用户创建课题草稿] --> B[配置报名时间、人数上限、审核开关]
    B --> C[添加与排序模块]
    C --> D[配置联系方式与入群二维码]
    D --> E[发布课题]
    E --> F{到达 signup_start}
    F -- 是 --> G[状态：报名中]
    G --> H{到达 signup_end}
    H -- 否 --> I[学生报名与取消报名]
    I --> G
    H -- 是 --> J[状态：报名截止，申请书锁定]
    J --> K{need_review 为真}
    K -- 是 --> L[评审申请书]
    L --> M[状态：审核中]
    K -- 否 --> M
    M --> N[状态：进行中，成员与任务执行]
    N --> O{到达 project_end}
    O -- 是 --> P[状态：已完成，成果自动归档]
    E -.任意阶段.-> Q[取消课题]
    Q --> R[状态：已取消，通知已报名学生]
```

**关键规则**：D9（已发布/报名中边界）、D18（完成即归档）、BR-08（删除/取消须通知）。

### BP-03 学生报名与申请书提交

```mermaid
flowchart TD
    A[学生打开课题详情页] --> B{已登录且为 USER}
    B -- 否 --> C[跳转登录页]
    C --> B
    B -- 是 --> D{状态为报名中且时间窗口内}
    D -- 否 --> E[按钮置灰：未开始或已截止]
    D -- 是 --> F{本人已报名该课题}
    F -- 是 --> G[显示本人报名状态]
    F -- 否 --> H{名额已满}
    H -- 是 --> I[提示已满员]
    H -- 否 --> J[填写报名表单：意向模块、备注、简历三选一]
    J --> K{need_review 为真}
    K -- 是 --> L[填写并提交申请书]
    L --> M{申请书校验通过}
    M -- 否 --> N[保存草稿或提示修改]
    N --> L
    M -- 是 --> P[报名 PENDING 待评审，占用名额]
    K -- 否 --> P1[报名 APPROVED，创建成员待分配模块]
    P --> Q[站内信通知报名成功]
    P1 --> Q
    Q --> R[展示联系方式与入群二维码]
```

**关键规则**：BR-03/04/05/09（名额、唯一、截止、不超卖）、D7（公开浏览）、D10（免审直通）、D16（报名与申请书同流程提交）。

### BP-04 报名审核（申请书评审）

```mermaid
flowchart TD
    A[管理用户进入报名管理页] --> B[按状态筛选报名与申请书]
    B --> C[查看学生信息、申请书、简历、附件]
    C --> D{评审决定}
    D -- 通过 --> E[报名 APPROVED]
    E --> F[创建课题成员，模块待分配]
    F --> G[记录评审人、时间、评语、评分]
    G --> H[通知学生评审结果]
    D -- 待定 --> I[报名 ON_HOLD，保留名额]
    I --> G
    D -- 拒绝 --> J[报名 REJECTED]
    J --> K{配置：拒绝后释放名额}
    K -- 是 --> L[释放名额，截止前可继续报名]
    K -- 否 --> M[名额不释放]
    L --> G
    M --> G
    H --> N[学生查看结果与分配模块]
```

**关键规则**：D8（PENDING/ON_HOLD 拆分）、D12（释放后截止前可再报名）、BR-16（释放名额可配置）、REQ-REV-03/07（评语评分、评审留痕）。

### BP-05 成员分配与任务进度

```mermaid
flowchart TD
    A[成员已创建] --> B[管理用户分配成员到模块]
    B --> C[站内信通知分配结果]
    C --> D[管理用户创建任务并指定负责人]
    D --> E[负责人更新状态与进度]
    E --> F[写入进度日志]
    F --> G{进度为 100}
    G -- 是 --> H[自动置为 DONE]
    G -- 否 --> I{超过截止时间}
    I -- 是 --> J[站内信逾期提醒]
    I -- 否 --> E
    J --> E
    H --> K{课题结束}
    K -- 是 --> L[成员状态 COMPLETED]
    K -- 否 --> E
    B -.调整或退出.-> M[调整模块或移除成员]
    M --> N[记录原因，任务重新分配或标记]
    N --> C
```

**关键规则**：BR-17（一成员一模块）、BR-18（负责人须为成员）、BR-19（进度留痕）、D13（模块删除保护）、D14（DONE 与 100% 联动）。

### BP-06 成果提交、审核与归档

```mermaid
flowchart TD
    A[成员或管理用户发起成果] --> B{保存草稿还是提交}
    B -- 草稿 --> C[状态 DRAFT，可反复编辑]
    C --> B
    B -- 提交 --> D{课题进行中或已完成}
    D -- 否 --> E[拒绝提交并提示状态不允许]
    D -- 是 --> F[状态 PENDING 待审核]
    F --> G[管理用户审核]
    G --> H{审核通过}
    H -- 是 --> I[状态 APPROVED]
    I --> J[课题详情页、成果页、个人主页展示]
    H -- 否 --> K[状态 REJECTED，附评语]
    K --> L[提交人修改后重新提交]
    L --> F
    J --> M{课题转为已完成}
    M -- 是 --> N[成果自动归档，支持导出清单]
```

**关键规则**：BR-20（审核通过才公开）、D18（完成自动归档）、REQ-ACH-04（拒绝须填原因）。

### BP-07 课题联系方式与入群二维码

```mermaid
flowchart TD
    A[管理用户在课题页填写联系方式] --> B[上传入群二维码]
    B --> C{格式与大小校验}
    C -- 否 --> D[提示错误并重新上传]
    D --> B
    C -- 是 --> E[设置可见性档位，默认报名后可见]
    E --> F[保存成功]
    F --> G[通知已报名学生联系方式更新]
    G --> H[学生访问课题详情页或我的报名]
    H --> I{满足可见性条件}
    I -- 否 --> J[显示占位提示，接口不返回数据]
    I -- 是 --> K[展示联系方式与二维码]
    K --> L[点击放大或长按识别，提示请勿外传]
```

**关键规则**：BR-26（可见性鉴权、禁公开直链）、D1（默认报名后可见）、D3（课题级单份）、D5（不加水印，仅文案提示）。
